### Memeriksa Detail Sistem Komputer (Windows)

#### A. Langkah-langkah Akses

| No | Aksi / Shortcut | Fungsi |
| :---: | :--- | :--- |
| 1 | `Windows + E` | Membuka File Explorer. |
| 2 | Klik kanan **"This PC"** → **Properties** | Melihat detail sistem komputer. |
| 3 | Menu **Settings → About** | Menampilkan informasi komputer. |
| 4 | `Ctrl + Shift + Esc` | Membuka Task Manager untuk memantau aplikasi yang berjalan di latar belakang. |
