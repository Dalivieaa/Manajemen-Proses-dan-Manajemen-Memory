### Perintah Restart & Shutdown Ubuntu di Terminal Linux

| No | Perintah | Penjelasan |
| :---: | :--- | :--- |
| 1 | `sudo reboot` | Mematikan dan menyalakan ulang mesin laptop di VirtualBox secara otomatis (restart). |
| 2 | Muncul logo Ubuntu dan ikon | Menandakan sistem sedang memproses data untuk masuk kembali ke menu utama. |
| 3 | Tampilan desktop Ubuntu | Proses restart selesai dan perangkat sudah bisa digunakan kembali. |
| 4 | `sudo shutdown now` | Mematikan total mesin laptop VirtualBox saat itu juga (langsung mati). |
| 5 | Muncul logo Ubuntu dan ikon | Menandakan sistem sedang memproses data untuk masuk kembali ke menu utama. |
| 6 | Status **"Powered Off"** | Menandakan proses mematikan Ubuntu telah berhasil dijalankan sepenuhnya. |
| 7 | Layar login | Layar sebelum masuk ke sistem; pengguna perlu memasukkan kata sandi untuk mengakses akun Ubuntu. |
| 8 | `sudo shutdown -r 12:43` | Menjadwalkan kapan laptop akan mati otomatis tepat pada jam 13:14. *(Catatan: format penjadwalan biasanya `HH:MM`)* |
