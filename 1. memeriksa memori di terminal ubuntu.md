### Memeriksa Memori & CPU

| No | Perintah | Fungsi |
| :---: | :--- | :--- |
| 1 | `free -h` | Melihat penggunaan kapasitas dan sisa RAM dalam format mudah dibaca (GB dan MB). |
| 2 | `sudo apt update` | Memperbarui daftar paket agar saat menginstal aplikasi mendapatkan versi terbaru yang stabil. |
| 3 | `sudo apt install htop` | Mengunduh dan menginstal aplikasi "htop" ke dalam sistem Ubuntu. |
| 4 | `htop` | Menampilkan penggunaan CPU, jumlah aplikasi yang berjalan, dan RAM yang tersedia secara interaktif. |
| 5 | `cat /proc/meminfo` | Menampilkan detail lengkap memori sistem (RAM). |
| 6 | `cat /proc/cpuinfo` | Menampilkan detail lengkap prosesor: model, kecepatan, dan fitur tiap core. |
| 7 | `lscpu` | Menampilkan ringkasan informasi arsitektur CPU agar lebih mudah dibaca. |
| 8 | `swap` | Melihat status, ukuran, dan jenis memori cadangan (Swap) yang aktif di sistem. |
| 9 | `vmstat -s` | Menampilkan penggunaan memori dan aktivitas sistem sejak laptop dinyalakan. |
| 10 | `ps aux --sort=%mem \| head` | Menampilkan daftar aplikasi yang paling banyak memakan RAM (peringkat teratas). |

### Perintah Editor NANO

| No | Perintah | Fungsi |
| :---: | :--- | :--- |
| 1a | `nano text.sh` | Membuka editor untuk membuat file text Shell. |
| 1b | `nano text.sh` (dengan `echo`) | Menampilkan teks ke layar yang sudah diketik di dalam file Shell. |
| 2a | `nano test.py` | Membuat file program bahasa Python. |
| 2b | `nano teks.py` (dengan `print`) | Menampilkan teks ke layar yang sudah diketik di dalam file Python. |
